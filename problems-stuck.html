// the hard problem

you have a specific, difficult problem and you're stuck.

sometimes the documented boundary is real. a lot of the time it is only the boundary of the methods already tried. we decompose the apparent limit into smaller uncertainties that can be investigated.

touches:

how we approach it

  • reconstruct the problem, including its history and failed approaches;
  • challenge the boundary and the assumptions holding it in place;
  • bring together whatever technical disciplines the problem crosses;
  • design experiments that produce early, decision-relevant evidence;
  • build the smallest useful thing that can reveal a path forward.

an initial engagement might produce

a reframed problem, a set of ranked technical hypotheses, rapid experiments and a working prototype or clear account of the remaining boundary.
